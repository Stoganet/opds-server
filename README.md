# opds-server

Minimal OPDS feed server for browsing and downloading a
[Chaptarr](https://github.com/Chaptarr/chaptarr)-organized ebook library
(e.g. from a Kobo running [KOReader](https://koreader.rocks/)).

Serves a flat OPDS Atom feed listing every `.epub` found under a mounted
library folder, with per-book cover extraction and direct download.
